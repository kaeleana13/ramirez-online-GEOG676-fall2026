# GEOG 676 Lab 7: Raster Analysis

This lab uses ArcPy to create a composite raster from four Landsat bands. It also creates a hillshade and slope raster from a DEM.

## Files

- `ramirez_lab7_raster.py` - Python code
- `ramirez_lab7_composite.png` - Composite raster result
- `ramirez_lab7_hillshade.png` - Hillshade raster result
- `ramirez_lab7_slope.png` - Slope raster result
