#GEOG 676 Lab 6: Map Generation Toolbox

This lab creates a Python toolbox that makes a graduated color map in ArcGIS Pro. I chose to create the map using the GarageParking layer because its Shape_Area field could be classified to show the differences in parking-area sizes. The layer was divided into five graduated color classes.

The toolbox also uses a progressor to show each step while the map is being created.

## Files

- `ramirez_lab6_maptool.pyt` - Python toolbox
- `ramirez_lab6_results.png` - Screenshot of the completed graduated color map
